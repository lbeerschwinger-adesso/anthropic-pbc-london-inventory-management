Data Flow

A filtered request, end to end

1

User changes a filter

In FilterBar.vue the user picks a warehouse, category, status or period. The shared useFilters composable holds these as module-level refs, so the selection persists across route changes.

2

View requests fresh data

The active view (e.g. Orders.vue) calls getCurrentFilters() — which maps selectedPeriod → month — and passes the result to an api.* function.

3

api.js builds the request

api.js serializes filters with URLSearchParams, skipping any value equal to 'all', then issues an Axios GET to http://localhost:8001/api/....

4

FastAPI handles & filters

The matching handler in main.py receives the query params and runs apply_filters() (warehouse / category / status, case-insensitive) and filter_by_month() over the in-memory lists.

5

Pydantic validates the response

Results are returned through a response_model (e.g. List[Order]), guaranteeing the JSON shape before it leaves the server.

6

UI reacts

Axios resolves response.data into a ref; Vue's reactivity recomputes derived computed values (totals, counts, charts) and re-renders the table — no manual DOM work.

Design Notes

Characteristics & demo constraints

State Singleton composables

Filters live as module-level refs in useFilters, giving global, route-persistent state without Vuex/Pinia.

Validation Pydantic everywhere

Every list/detail endpoint declares a response_model, so payloads are shape-checked before reaching the client.

Demo No database

All data is loaded from JSON into memory at startup. Writes don't persist — restarting the server reloads the original files.

Dev only Open CORS, no auth

The API allows all origins and has no authentication or rate limiting. Suitable strictly for local demonstration.

i18n EN / JA

Locale and currency (USD/JPY) are switchable and persisted to localStorage via useI18n.

Gap Stubbed client calls

api.js defines task and purchase-order calls (tasks, purchase-orders) that have no matching backend route yet — they fail gracefully in the UI.
